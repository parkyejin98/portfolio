디블럭 APP UI 기획
21.10
외주사 '디블럭'에서 주유소에 에어컨 필터를 택배로 납품하는 사업 구조에 맞춰, 재고 관리를 효율화하기 위한 전용 어플리케이션의 화면 설계 및 서비스 기획을 담당했습니다. 단순 주문 기능이 아닌, 주유소별 입고·출고 현황과 잔여 재고를 실시간으로 확인할 수 있도록 전체 서비스 흐름을 설계했습니다. 먼저 실제 운영 프로세스를 분석하여 발주 → 배송 → 입고 확인 → 재고 차감으로 이어지는 업무 단계를 정리했고, 이를 기반으로 사용자 동선에 맞춘 와이어프레임을 제작했습니다. 특히 현장 직원이 모바일 환경에서 빠르게 사용할 수 있도록 화면 구조를 단순화하고, 수량 입력 및 재주문 기능을 직관적으로 배치했습니다.
모아요 APP UI 기획
21.08~21.09
B2B 플랫폼 ‘모아요’ 프로젝트에서는 외주사 ‘금호자원’과 미팅을 통해 요구사항을 직접 수집하고 조율한 뒤, 이를 기반으로 서비스 구조를 설계하고 와이어프레임을 제작했습니다. 폐기물 업계 특성상 수기 문서와 지인 소개 중심의 비효율적인 업무 구조를 개선하기 위해 ‘올바로’, ‘코라’ 폐기물 API를 연동한 데이터 관리 시스템을 기획했습니다. 단순 화면 구현을 넘어, 플랫폼 내 데이터 저장·조회·이력 관리 구조를 설계하여 운영자가 효율적으로 관리할 수 있는 관리자 환경을 구현했습니다. 이후 Html5 기반의 하이브리드 WebApp과 관리자 페이지를 직접 기획·제작하여 실제 앱 출시까지 이어졌습니다.

2020. 09 ~ 2020. 12
