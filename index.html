한국 스마트 홈 산업협회/주경야독

2020. 09 ~ 2020. 12

Eclipse로 Java, jsp, html, css를 통해 "화해(화장품을 해석하다)"라는 팀 프로젝트를 진행했습니다. 코로나 시대가 도래해 마스크를 장시간 착용해 피부고민 문제가 생긴 사람들이 증가한 것에서 문제점을 착안해 피부관리 화장품 성분 분석 및 맞춤 추천 웹사이트를 개발했습니다. 그 중 로그인 기능을 담당으로 로그인, 로그아웃, 회원가입, 회원탈퇴, 회원정보수정 등을 다뤘으며 html 능력, 자바 스크립트로 함수를 만드는 능력, 아이디 중복 확인을 할 때 DB에 중복된 데이터가 있는지 검사하는 SQL 문 작성 능력이 향상했습니다.

2020. 04 ~ 2020. 08

Eclipse로 Java, jsp, html, css를 통해 "Share Recipe"라는 요리 사이트의 검색 기능을 담당했습니다. 프로젝트를 통해 팀원들을 선도하고 이견조율을 하는 능력, 검색 기능구현을 위해 DB의 SQL 문 작성 능력, 검색 필터 기능을 구성하기 위해 html 능력이 향상했습니다.
